# MMS Core Docs

Shared documentation for all 3 subsystems: Web, MilitianApp, PoliceApp.

## Structure
- `business/` - Business flows, requirements
- `user-stories/` - User stories and scope lock
- `technical/` - Technical specs, API, ERD, UI specs
- `testing/` - UAT cases, test scenarios, E2E test plans
- `manuals/` - User manuals, operational guides
- `retrospects/` - Retrospective notes

## Ownership rules
- Shared docs (apply to >= 2 subsystems) -> place here
- Web-specific docs -> `C:/MMS/Web/docs`
- MilitianApp-specific docs -> `C:/MMS/MilitianApp/docs`
- PoliceApp-specific docs -> `C:/MMS/PoliceApp/docs`

## Cross-references
When a subsystem doc needs shared context, link to this directory rather than duplicating.
